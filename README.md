# ITE Math Lab

Interactive web visualizers for **Mathematical Applications for ITE**.

## Topics

- **Set Theory:** Venn diagrams that shade any set expression, plus cardinality, inclusion–exclusion, power sets and Cartesian products
- **Logic & Truth Tables:** truth tables for compound propositions, with tautology and contradiction detection
- **Relations & Functions:** relation matrix, directed graph, and checks for the relation's properties
- **Matrix Operations:** addition, multiplication, transpose, determinant and inverse, with step-by-step working
- **Matrix Transformations:** 2×2 matrices applied to the plane, shown with an animation
- **Number Systems:** conversion between binary, octal, decimal and hex, with the working shown
- **Counting:** permutations, combinations, Pascal's triangle and password counts

## Run it

Open `index.html` in any browser. It needs no build step and no dependencies.
